# VivaDecor - Modern & Luxury Interior Design Website

A modern, high-converting, fully responsive web application for VivaDecor Interior Design Studio.

## ✨ Features
- **Hero Showcase**: High-impact luxury hero section with interactive consultation triggers.
- **Before / After Comparison Slider**: Interactive interactive split-view renovation visualizer.
- **Interactive Project Showcase**: Filterable portfolio with modal view and project specs.
- **Cost Estimator / Calculator**: Real-time renovation cost estimator by room type, style, and square footage.
- **AI Design Assistant**: Integrated Zander AI chatbot widget for 24/7 design inquiries.
- **Reviews & Testimonials**: Verified client reviews and rating showcase.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack
- HTML5 / Semantic Layout
- Modern Vanilla CSS (Flexbox, CSS Grid, Custom Properties, Glassmorphism, Micro-interactions)
- Vanilla JavaScript (ES6+)
- Google Fonts (Playfair Display & Inter)

## 🚀 Getting Started
Simply open `index.html` in any modern web browser or serve it via a local static web server.
